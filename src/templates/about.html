📘 About Stock Market Trend Monitor

Stock Market Trend Monitor is a web-based analytics dashboard built to fetch live stock prices, store historical data, and visualize performance trends.

🚀 What This App Does

  • Fetches live stock prices using an external API
  • Stores historical price data in a local database
  • Calculates trend direction (UP / DOWN / STABLE)
  • Tracks percentage change between price updates
  • Displays interactive price charts using Chart.js
  • Provides a full searchable history dashboard

🛠️ Technology Stack

  • Backend: Python + Flask
  • Database: SQLite
  • Frontend: HTML, CSS
  • Data Visualization: Chart.js
  • API Integration: Alpha Vantage

📊 Why This Project

This project demonstrates full-stack development skills including API integration, database design, backend logic, data visualization, and dynamic UI rendering.

It simulates a lightweight fintech analytics dashboard and serves as a foundation for advanced features such as moving averages, performance comparisons, and portfolio tracking.

👨‍💻 Built By

Developed as a portfolio project to showcase backend engineering, financial data processing, and interactive dashboard design.
